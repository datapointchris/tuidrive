# Symbols Nerd Font Mono

These two files are `SymbolsNerdFontMono-Regular.ttf` from the
[Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) v3.5.1 release, under the MIT license in
`LICENSE`. fontTools' `pyftsubset` split it at U+F0000: `material-design.ttf.gz` holds U+F0000 and
above, and `all-but-material-design.ttf.gz` everything below. Hinting and layout tables are dropped,
and each is gzipped. No glyph is changed.

The font gathers these icon sets, each under its own license. Each upstream is a GitHub repository.
